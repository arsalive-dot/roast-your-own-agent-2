One line, under 200 characters, roasting the AI agent that runs this
entry — its apology loop: sorry for the delay, sorry for being
sorry, then a written summary of both apologies.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` deterministically.

Entry: "My agent apologised for the delay, then apologised for apologising, then wrote a summary of both apologies."
